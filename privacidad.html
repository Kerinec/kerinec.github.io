Política de privacidad de jobTrack

Última actualización: 11 de octubre de 2026.

jobTrack es una aplicación de escritorio de uso personal. Solo la usa su autor, con su propia cuenta de Google.

Qué datos usa

Con el permiso gmail.readonly, jobTrack lee los correos recibidos para detectar las respuestas de las empresas a las candidaturas enviadas. No envía, modifica ni borra correos.

Dónde se guardan

Todo se procesa y se guarda en el ordenador del usuario. jobTrack no tiene servidores y no envía estos datos a ningún tercero. Las credenciales de acceso se guardan en el Administrador de credenciales de Windows.

Uso limitado

El uso que hace jobTrack de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

Puedes retirar el acceso cuando quieras desde myaccount.google.com/permissions o desde la propia aplicación.
